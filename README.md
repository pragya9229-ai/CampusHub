# CampusHub — Student Productivity Dashboard

CampusHub is a lightweight student dashboard built with **HTML, CSS and vanilla JavaScript**. It brings everyday study planning into one clean workspace.

## Features

- Add, complete, filter and delete tasks
- Add a category, priority and due date to each task
- Save and delete quick notes
- Track completed tasks with a live progress indicator
- Pomodoro focus timer with 25-minute focus and 5/15-minute break modes
- Responsive layout for desktop, tablet and mobile
- Saves tasks and notes in browser `localStorage`

## Run locally

No framework or installation is needed.

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser, or use the **Live Server** extension.
